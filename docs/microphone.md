# Микрофон для Windows

1. Запустите **Air Remote Setup** с компонентом микрофона. Оригинальный [VB-CABLE от VB-Audio](https://vb-audio.com/Cable/) включён в пакет; это donationware, автора можно поддержать. Уже установленный кабель сохраняется. После первой установки драйвера перезагрузите ПК.
2. На телефоне: **ПК → Устройства → Компаньон → Сканировать QR** из окна Air Remote. Оба устройства — в одной локальной сети.
3. Во вкладке **Микрофон** нажмите **Включить микрофон**.
4. В Discord, OBS или другом приложении выберите **CABLE Output**. Компаньон сам выбирает CABLE Input; настройки звука и панель кабеля доступны в его окне.

**Речь** использует обработку телефона; **Естественный звук** запрашивает запись без обработки. Передаётся 48 кГц, моно. Запись работает при блокировке телефона; остановка и выключение звука доступны в уведомлении.
