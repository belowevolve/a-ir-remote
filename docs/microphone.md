# Микрофон для Windows

## Первый запуск

1. Установите [VB-CABLE](https://vb-audio.com/Cable/) и перезагрузите ПК.
2. Запустите [AndroidMic](https://github.com/teamclouday/AndroidMic/releases), выберите **TCP**, выход **CABLE Input** и нажмите Connect. Разрешите подключение в брандмауэре для частной сети.
3. Подключите телефон к той же сети. В Air Remote укажите IPv4 компьютера из `ipconfig` и порт AndroidMic (обычно **54345**), нажмите **Подключить**.
4. В Discord, OBS или другом приложении выберите микрофон **CABLE Output**.

**Речь** включает обработку голоса, **Естественный звук** запрашивает запись без обработки. Передаётся звук 48 кГц, моно. Для меньшей задержки используйте стабильный Wi-Fi и небольшой буфер в AndroidMic.

Запись работает при блокировке телефона. Выключить звук или остановить передачу можно в приложении и уведомлении. После разрыва подключитесь заново. Микрофон для ПК и голосовой ввод ТВ одновременно не работают.
