# Микрофон для Windows

Телефон → Wi-Fi → VB-CABLE → Discord, OBS или другое приложение.

1. Установите [Air Remote Setup (.exe)](https://github.com/belowevolve/a-ir-remote/releases/download/v0.1.36/Air-Remote-Setup-0.5.6.exe) с компонентом микрофона. После первой установки драйвера перезагрузите ПК.
2. На телефоне: **ПК → Устройства → Компаньон → Сканировать QR** из окна Air Remote. Оба устройства должны быть в одной Wi-Fi-сети.
3. Во вкладке **Микрофон** нажмите **Включить микрофон**.
4. В приложении на ПК выберите **CABLE Output**. Компаньон выбирает **CABLE Input** автоматически.

**Речь** — обработка звука телефоном. **Естественный звук** — запись без обработки, если её поддерживает устройство.

48 кГц · моно. Запись работает при блокировке телефона; звук и остановка доступны в уведомлении.

[VB-CABLE](https://vb-audio.com/Cable/) включён в установщик. Donationware от VB-Audio; существующий драйвер сохраняется.
