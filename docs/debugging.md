# Проверка исправлений пульта

## Несколько телефонов

На Haier Android TV PRO (Android 14) изучена установленная служба
`com.google.android.tv.remote.service`. Её `KeyStoreManager.storeCertificate`
удаляет предыдущие сертификаты с совпадающим `getSubjectX500Principal().getName()`
перед сохранением нового сертификата. У старого Air Remote это всегда
`CN=Air Remote`: повторное сопряжение другого телефона вытесняет первый.

Исправление: отдельный UUID в subject сертификата каждой установки, постоянный
ключ `air-remote-client-tls-v2` в Android Keystore. Старый ключ сохраняется для
ранее сопряжённых телевизоров. При успешном новом сопряжении только этот ТВ
переключается на новый ключ. Для исправления старых конфликтующих сопряжений
нужно обновить и заново сопрячь каждый телефон.

Проверить на двух телефонах: сопрячь A, затем B, отправить команды с обоих;
закрыть и открыть A, затем B; убедиться, что новый PIN больше не требуется.
Одновременное использование двух физических телефонов пока не проверено.
